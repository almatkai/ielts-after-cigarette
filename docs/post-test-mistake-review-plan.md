# Работа над ошибками

Обновлено: 2026-10-08. Статус: реализовано в worktree; публикация и интеграция с гостевой веткой не выполнялись.

## Поведение

После завершения теста сразу открывается «Работа над ошибками» этого теста. Экран повторяет список карточек из присланного примера: номер и вопрос, «Ваш ответ», отметка ошибки, кнопка «Разобрать ошибку».

Ученик выбирает любую ошибку и открывает существующий диалог разбора. Правильные ответы и объяснения не раскрываются в списке заранее.

В диалоге кнопка «Следующая ошибка» открывает следующую доступную ошибку той же попытки, без закрытия окна. Состояние ответа и подсказки сбрасывается; отметка «Разобрано» предыдущей ошибки сохраняется. Верные и закрытые вопросы пропускаются, на последней доступной ошибке кнопки нет. Переход проверен browser-тестами для Reading и Listening, включая мобильный экран.

Кнопка перехода находится в отдельной нижней панели вне прокрутки разбора и не перекрывает объяснение. После раскрытия Listening-решения остаётся одна компактная кнопка «Слушать ответ»; время фрагмента указано один раз возле цитаты. 14 post-test browser-сценариев прошли, включая длинное объяснение и геометрию кнопок на ширине 1024 и 375 px. В браузере отдельно проверен конец длинного объяснения над нижней панелью.

### Отдельный тест

- Заголовок «Работа над ошибками», название пройденного теста и количество ошибок.
- Сразу список ошибок именно завершённой попытки.
- Без tab bar навыков и выбора других попыток.
- Существующий результат теста сохраняется; список ошибок становится основным содержимым после сдачи.

### Full Mock

- Сохраняются общий результат и карточки Listening, Reading, Writing, Speaking.
- Нажатие на карточку секции открывает её работу над ошибками в рамках этого Full Mock.
- В разборе есть tab bar Listening / Reading / Writing / Speaking. Выбрана секция, на которую нажали.
- Переключение вкладки показывает только соответствующую попытку из той же Full Mock session: Reading — ошибки Reading, Listening — ошибки Listening.
- Writing/Speaking показывают существующий разбор и рекомендации соответствующей секции. Новая AI-проверка не добавляется.
- Возврат к результату сохраняет контекст этого экзамена.

### Текст и элементы

- Название экрана: «Работа над ошибками».
- Кнопка у вопроса: «Разобрать ошибку».
- Для пустого списка: «Нет ошибок».
- Для ожидающей AI-проверки секции: «Проверяется».
- Никаких вступлений, объяснений назначения страницы и повторяющихся призывов.
- В этом экране нет «Банк ошибок», «К списку попыток», «Обновить» и дополнительной кнопки «Полный разбор».
- Общий раздел с историей ошибок остаётся отдельным разделом. После сдачи не отправляем ученика выбирать тест заново.

## Реализация

1. **Выделить общий список ошибок попытки.** Переиспользовать `MistakeRow` и диалог. В компонент передавать attempt и разрешённый review; убрать навигацию банка попыток. Сохранить контекст completion-заданий, options, текст и аудио.
2. **Подключить отдельные тесты.** После сдачи показывать список текущего теста сразу. Тот же экран использовать при повторном открытии этой попытки. Tab bar навыков здесь не рендерить.
3. **Подключить Full Mock.** Карточка выбирает section attempt из текущей session. В разбор передавать session context и выбранную секцию; вкладки меняют attempt только внутри этой session. Прямое открытие ссылки и перезагрузка должны сохранять выбранную секцию.
4. **Учесть доступ гостя.** Использовать серверные `guestPreview`/`locked` из guest-ветки. Доступные 30% ошибок открывают разбор, остальные — вход. Секция выбирается независимо от закрытой оценки: выбор Reading должен позволять увидеть доступные ошибки Reading. Нажатие на закрытую оценку сохраняет существующее предложение войти.
5. **Проверить переходы и мобильный экран.** Сдача → ошибки текущего теста, Full Mock → выбранная секция, переключение вкладок, открытие/закрытие диалога, возврат и перезагрузка.

Использовать существующие attempt/review/material API. Новый endpoint, принудительное последовательное прохождение всех ошибок и отдельный итог разбора не входят в эту задачу.

Дополнение по просьбе пользователя: после правильного повторного ответа карточка получает зелёную отметку «Разобрано». Отметка сохраняется в браузере для пользователя, попытки и вопроса, переживает перезагрузку и переключение секций. Неверный повторный ответ или просмотр решения её не ставят. Исходные ответы, балл и число ошибок экзамена не меняются; между устройствами отметка не синхронизируется.

При переиспользовании диалога проверить известные несовпадения его проверки с grading: полный набор `optionIds`, TFNG/YNNG без подмены YES/TRUE, точный контекст Passage/Part. Не показывать фиктивные варианты A–D при отсутствии данных. Разбор не изменяет сохранённые ответы и исходный band.

## Приёмка

- Завершение отдельного Reading/Listening сразу показывает его ошибки; вкладок навыков нет.
- В Full Mock нажатие Reading открывает Reading выбранного экзамена и активирует соответствующую вкладку.
- Все четыре вкладки работают только с секциями текущего Full Mock; чужие или старые попытки не попадают в список.
- Любую карточку можно открыть через «Разобрать ошибку», без обязательной очереди.
- В списке есть собственный ответ; правильный ответ находится внутри разбора.
- Заголовок — «Работа над ошибками», без текста и навигации банка попыток.
- Ноль ошибок, загрузка, ошибка сети и ожидающая оценка имеют короткие корректные состояния.
- Гостевые ограничения сохраняются; после входа открывается тот же тест без устаревшего blur.
- На телефоне карточки, tab bar Full Mock и диалог работают без горизонтального скролла.
- Для аудио используется короткий контекст вокруг приблизительных меток распознавания: 4 секунды до и 1 после, с округлением наружу и ограничением длительностью записи. Показанный диапазон совпадает с воспроизведением. Проверка реального Cambridge 19 Listening Test 3, вопрос 2: исходные 137,3–141,5 с обрезали слово bridge; фрагмент 133–143 с содержит всю цитату. Это запас при воспроизведении, а не новая точная привязка слов в опубликованном материале.

Проверки при реализации: сценарии переходов в browser tests, существующие regression tests, TypeScript и frontend build. Для изменения проверки повторного ответа — отдельные случаи multiple choice и TFNG/YNNG. Платные AI-провайдеры в browser fixtures не запускаются.
