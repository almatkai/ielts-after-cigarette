# Правила дизайна IAC

Этот документ фиксирует визуальные и продуктовые принципы проекта. Используйте
его как короткий чек-лист перед созданием новых экранов.

## Характер интерфейса

- Спокойный, точный и минималистичный образовательный продукт.
- Каждый блок решает одну понятную задачу. Декор не должен конкурировать с
  содержанием.
- Интерфейс полностью на русском языке, кроме устоявшихся названий форматов и
  экзаменов: IELTS, Academic, General Training.
- В рабочих экранах не использовать вымышленные данные. До подключения
  бэкенда показывать пустые поля, понятные подсказки и продуманные empty states.

## Цвета

| Назначение                    | Цвет      |
| ----------------------------- | --------- |
| Основной фон                  | `#FAFAF8` |
| Фон дашборда                  | `#F7F7F5` |
| Карточка                      | `#FFFFFF` |
| Основной текст                | `#111111` |
| Вторичный текст               | `#69696D` |
| Приглушённый текст            | `#9A9A9D` |
| Основной акцент               | `#E23B3B` |
| Акцент при наведении          | `#C92F2F` |
| Светлая акцентная поверхность | `#FFF0F0` |
| Нейтральная поверхность       | `#F4F4F1` |
| Граница                       | `#E7E7E4` |

Красный используется для основного действия, активного состояния, короткого
акцента или ошибки. Он не должен занимать большие фоновые площади в рабочих
экранах.

## Типографика

- Основной шрифт — **Manrope Variable**.
- **Instrument Serif Italic** допустим только как редкий редакционный акцент на
  лендинге.
- Заголовки компактные, с отрицательным `letter-spacing`; основной текст —
  свободный, с удобным межстрочным интервалом.
- Не использовать капс для длинных фраз. Капс допустим для коротких eyebrow и
  служебных подписей с увеличенным межбуквенным интервалом.

## Сетка и размеры

- Контейнер лендинга: максимум `1240px`.
- Боковая панель дашборда: `268px`; верхняя панель: `72px`.
- Основной контент дашборда: внутренние отступы `20px` на мобильном, `28px` на
  планшете и `36px` на десктопе.
- Базовый шаг отступов — `4px`; основные интервалы строятся кратно `4` или `8`.
- Минимальная удобная область нажатия — `44 × 44px`.
- Карточки: радиус `12–18px`, тонкая граница `1px`, очень мягкая тень или без
  неё.

## Компоненты

- Сначала искать готовый компонент в `src/components/ui`.
- Базовый стек компонентов: shadcn/ui на Radix UI. Иконки — Lucide.
- Motion, Magic UI и React Bits использовать только тогда, когда движение
  объясняет состояние или усиливает конкретный визуальный образ.
- Не создавать локальную копию Button, Card, Input, Label, Select, Switch и
  других уже существующих примитивов.
- Формы группировать по смыслу. На одной карточке — одна задача и одно основное
  действие.

## Поля и состояния

- Поле имеет одну тонкую границу. При фокусе меняется цвет этой границы; второй
  контур или одновременно видимые border и ring не допускаются.
- Placeholder объясняет формат ввода, но не заменяет постоянный Label.
- Hover, focus, active, disabled и error должны быть визуально различимы.
- Ошибка обозначается не только цветом: добавлять понятный текст.
- Сохранять нативные `autocomplete`, типы полей и клавиатурную навигацию.

## Движение

- Анимации плавные и ненавязчивые; стандартная длительность интерфейсного
  перехода — `160–240ms`.
- Длительные фоновые эффекты не дублируются между секциями.
- Важный контент не зависит от анимации.
- Всегда учитывать `prefers-reduced-motion`.

## Адаптивность и доступность

- Экран должен оставаться рабочим от ширины `360px`.
- Сначала проектировать линейный мобильный поток, затем добавлять колонки.
- У интерактивных иконок есть доступное имя, у полей — связанный Label.
- Не удалять видимый focus без равноценной замены.
- Контраст текста и действий должен соответствовать WCAG AA.

## Финальная проверка

1. Весь пользовательский текст на русском языке.
2. Нет тестовых имён, email, статистики и других фиктивных данных.
3. Использованы существующие UI-компоненты.
4. У каждого блока есть одна ясная функция.
5. Поля не получают двойную рамку.
6. Экран проверен на мобильной и десктопной ширине.
7. Учтены клавиатура, focus и reduced motion.
